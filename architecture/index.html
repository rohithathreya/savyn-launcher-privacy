01

Ontology

Domain
A life: Fitness, Chess, Food. Holds a North Star (want / avoid / when) — a fixed thread, not a work path. The door may use one clause only when this app × this clock make that clause live.
Domain-next
Roster at domain height: one line per work thread + honest clock, or empty. Soonest clock first; unstructured (Game analysis) at the back. Not a chore list. Never skip-guilt. Never an invented 7:00.
Thread
Continuity lens (Nutrition ⊂ Food). Seeded, not auto-minted. Carries blurb (prose job for the beat), so-far (thin spine, folded each beat), episodes, next (its roster row). Brand-new: blurb only — no next, no so-far until a dump.
North Star
One editable paragraph. No next, no episodes, no blurb-as-form. About / rhythm retired; they seed this once, then die.
Episode
One dump a thread could file. Classify names the lens; the lens writes the beat; that beat is the episode. Does not wait for Sync. Do taps are not episodes.
Ideas
Facilitators on a path, not sibling threads. Lock-in does not mint threads from them.
Day
06:00 → 06:00 local. Door key = (domain, app) or (domain, none). Swiggy ≠ Hevy ≠ chess.com.
02

Sitting

  1. Open. App in domain, or domain tile. Before they speak: one callout. Chips iff a real Do exists. Else silence.
  2. Cache. Rewrite if stale (~1h) or day-part flipped. Dump that rewrote domain-next drops every key on that domain. Hide does not.
  3. Sit. Typed dump = user turn. Classify → parallel beats. Memory already filed.
  4. Do. Chip launches URL/app. Not a turn. No classify, no chorus, no continuation.
  5. Classify. Name threads this dump actually moved. Empty allowed. Reply-to-one → that thread only. Cap a handful. Never on Do.
  6. Beat (same call). Store episode, embed, fold so-far, rewrite next + next_at.
  7. Continue. After a dump, sitting unsynced: notice, not hello, not recap. Dies on Sync. Do does not trigger it.

Beat may see: dump (verbatim), prior dump on this sitting, this thread’s blurb / so-far / next / clock / ideas / prior beats, group faces, domain title.

Beat must not: other threads’ so-far, invented clocks, homework, skip/mute, echo-as-face, PGN/notation, clerk voice, a form.

03

Door packet

App-hour orientation. Not a sitting recap. Grain = the app’s name (Swiggy = order, Hevy = train).

Always
Now. Domain title. App display name if known. A handful of soonest domain-next lines.
North Star
Clipped, usually ignored. One clause iff this app × clock make it live (Swiggy 01:00 × avoid late-night snacking).
Never
Spine as a goal. So-far novels. Lifetime episodes. Today’s recaps. Unmerged beats. Invented clocks or nouns. A noon quote of a night avoid.
Line
≤24 words. Idea or question-statement. Never homework. Never a doorbell. Never a sitting essay.
Continuation
Last dump + chorus faces + soonest nexts + so-far. Does not overwrite the per-app starter cache. ≤22 words.
Browsing lunch options? Before you pick, quietly wait and watch cravings arise and pass.
04

Chips & objects

The door is a line. A chip is a Do or it does not exist. Max two. Live card, then pantry. Else nothing — no Sit fill. Two likely typed moves cycle as composer placeholders (“Suggest a meal”, “Log my order”). Sit taps are retired.

Do = open a URL or app the domain already has. Model may not invent URLs. Associated app is not a chip — they opened it from the widget. Verb from the object (“Caro lesson”), never “Open this.” Tap is not a turn.

Search exists iff next named a thing in the world a practitioner would Google. Vague practice (“keep training”) → no search. At most one query. Park one live card for chips only — never auto-write pantry. OG title is not the chip; verb is read from what the page is. Failures and next-changes clear the card.

05

Sync leaves.

Merge: always leave. Quiet: ~2h since last dump + substance; gate “still mid-arc?” — fail open. Hide ≠ Sync.

Does: stamp closed, wipe chorus, drop per-app door cache, maybe search a live object from the new nexts.

Does not: recap beats, rewrite so-far or next, mint threads, re-fold North Star. Identity folds on the dump if classify touched it.

07

Writers

Separate jobs. Separate prompts. “House” = thread, “track” = domain. Threads are never auto-created from a dump.

9.1 North Star

WhenOnce per domain. Fold on dump iff classify touched want / avoid / when. InCurrent guidelines only. OutOptional short fold into the same paragraph. Not a recap of the plate. FailPrior spine stands.

9.3 So-far

WhenSame beat as the episode. Never a chat field. InThis thread: name, blurb, prior so-far, next, dump, prior beats this sitting. Outso_far — advance what changed; do not retell the episode. FailKeep prior. Episode may still file.

9.4 Domain-next

WhenEvery beat (unless path closed). Also human edit in the book. Next-change clears live card. InSame as beat. Outnext ≤12 words, their nouns. next_at ISO / HH:mm / empty — honest clock only. FailOld next + clock remain. Guilt language stripped on write.

9.5 Episode

WhenAfter classify. Parallel per touched thread. Not Do. Not delayed to Sync. InYou are thread {name} + YOUR JOB (blurb). Domain. This thread’s so-far / next / clock / ideas / prior beats. Dump verbatim. Prior dump if follow-up. Group faces. Never URLs, never other so-fars. OutSee shapes. Face on the plate. Episode stored + embedded. So-far folded. Next rewritten. Domain callout cache dropped. FailSalvage or silence. Empty > polite recap.

9.6 Blurb

WhenOnboarding, manual add, one-time backfill, or they edit the book. OutProse charge. Not JSON. Not INPUT/INFERRED. Defaults (model down only): Nutrition → calories / profile / meal times; Fitness → parts + recovery; Game analysis → unstructured. North Star: none.

9.7 Classify

WhenEvery user dump. Skip if reply-to-one. Never Do. InDomain, dump, prior dump, threads (id, name, next, so-far), recent faces. Out{ touched: [ids] } from the packet. Empty allowed. North Star iff identity / avoid / when. FailAnalysis-shaped → analysis thread; else name-match; else quiet nothing.

9.8 Starter door

WhenLazy on open for (domain, app). Stale ~1h or day-part. Dump/Sync drop all keys on that domain. Slot pass does not rewrite all domains. InWeekday + clock, domain, app name, clipped North Star, soonest nexts. Outliner ≤24 · says×2 · do_object optional. Trash/guilt/homework rejected. Dos from live card / pantry only. FailSoonest next as the line. No Sit fill.

9.9 Continuation

When≥1 typed dump, newer than last Sync. Fingerprint = last turn. Not Do. InLast dump, chorus faces, soonest nexts + so-far, clipped North Star. OutLiner ≤22 · says×2 · optional do_object. Stored until Sync or a newer dump. FailSoonest next; if none, no plate.

9.11–14 Do / live / about / pantry

DoAfter liner. Live card then pantry. Max 2. Skip “Open this” / “Open {app}”. Prefer do_object match. No invented URL. None → silence; says still cycle. LiveAfter next rewrite. Pick ≤1 next that is a named object. { hub_id, object≤6, query } or empty. Query = practitioner Google. Reject tips/how-to/best/healthy/easy/quick. Never auto-save pantry. AboutURL already in hand. kind · nouns · verb · line. Never OG headline. Host heuristic on fail. PantryTheir saved rows vs nexts. { ids } ≤2 that serve that next. Fail → no pantry Dos.

9.15 Quiet gate

WhenUnsynced dumps and ~2h quiet. Manual Sync skips and always leaves. Out{ needs_merge }. True = leave room. False = overlay stays. Fail → true (fail open).

10

Trace

  1. Swiggy, 18:00, Food. Starter from soonest Food nexts. Says cycle. Do iff an object is in the room.
  2. Dump. Classify → Nutrition. Nutrition writes the beat (calories, profile, meal times), folds so-far, sets lunch clock. Game analysis silent.
  3. Continuation on the sitting. Swiggy cache untouched.
  4. Do tap opens a URL. No chorus.
  5. Hide: sitting still open. Memory already landed.
  6. Sync: chorus gone, Food door cache dropped. Next Swiggy open writes from the new roster.

One job. One packet. One shape.

Silence is cheaper than a lie.
