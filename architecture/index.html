00 · Thesis

Savyn is not a chatbot with a memory dump. It is a domain of life, holding threads of continuity. A thread is a lens. They dump; the lenses that actually moved write a beat that is the episode.

Four jobs stay separate on purpose. Collapse them into one voice and the product becomes a clerk: “paste the game,” “keep going,” “you skipped vision.” The system is built to refuse that.

JobOwnerFor
The doorCalloutWhat they’d be doing right now on this app — short, lived. Speaks from the soonest domain-next, not the whole board.
The readingThreadsWhat this dump meant for this path, following that thread’s beat-structure blurb.
Durable memoryThe beatOn the dump: write the episode, embed it, fold so-far, rewrite domain-next + clock. Sync only leaves the room.
The objectLinks & appsA real next they can tap — a video, a board, a lesson. Attached after the line. Never invented.

01 · Ontology

Domain

A life (Fitness, Chess, People). It holds a North Star: how they want to live here — want, avoid, when. That spine is a special fixed thread, not a work path. The door may softly mention one clause, only when this app + this clock make that clause live. It is not a goal and not a dump of the spine.

Domain next lives at domain height as a roster: one line per work thread, each with an expected timestamp when that thread has an honest clock. Threads with no clock (Game analysis) stay at the back. The door prioritizes the closest timestamp. Not a chore list, not skip-guilt, not seating copy. A line may name a thread noun (“protein’s thin — lunch is the hole”).

About and rhythm as separate dimensions are retired. They seed the North Star once, then they are gone.

Thread

A continuity lens inside a domain (Nutrition under Food; Training under Fitness). Not a topic tag. Not today’s anecdote. Not auto-minted from a sitting. The first set is seeded; they tweak after.

  • Beat-structure blurb — prose, written at create, editable in the thread book. Charge for the LLM: what to infer from a dump. Not JSON. Nutrition might say daily calories, nutritional profile, meal times. Game analysis might say this path is unstructured — so it stays unstructured. Replaces the old INPUT / INFERRED beat legs.
  • So far — the thin spine of this path across sittings. Folded forward on each beat. Cap is short on purpose.
  • Episodes — each filed beat is an episode. Write, embed, store. Not a later recap of a sitting buffer.
  • Next — this thread’s one line on the domain-next roster, plus an expected timestamp when the dump implies an honest clock. Empty clock if unstructured — never invent 7:00. Brand-new threads have no next until a dump writes one. Never “you skipped / missed / muted.”

North Star is special: one editable prose paragraph. No next. No episodes. No blurb-as-form. A thread may also hold ideas: facilitators on the path, not sibling threads. Lock-in does not mint new threads from them.

Episode

One dump a thread could file. They typed; classify named this lens; the lens wrote the beat. That beat is the episode. It does not wait for Sync.

A sitting can still be the open overlay (chorus, hide ≠ close). Chat can stay. Memory must not wait for Sync. Sync is leaving the room, not the memory writer.

Do taps do not start an episode. They open a URL or app. Never a turn, never a beat, never a thread line.

02 · Sitting algorithm

They tap Fitness on the widget and open the training app. The machine then runs this, and only this.

  1. Open. App in this domain, or the domain with no app. Before they have spoken, Savyn owes a callout: one short line. Chips only if a real Do exists. Otherwise silence — they type.
  2. Key. Cache is (domain, app). Swiggy ≠ Hevy ≠ chess.com. A day is 6am → 6am, local. Rewrite lazily on open if stale (~1 hour) or day-part flipped. A dump that rewrote domain-next drops the cache. Overlay hide does not.
  3. Sit. They type. That text is a user turn. Classify. Touched threads write episode beats. Memory is already filed.
  4. Do. They tap a chip that opens a link or an app. Launch happens. That is not a sitting turn. No classify, no chorus, no clerk copy.
  5. Classify. Name every thread this move actually moved. Silence only if nothing is there to file. If they replied to one member, only that thread answers. Up to a handful write in parallel. Each follows its own blurb. No clarifying question. Infer and write.
  6. Beat, same call. Episode stored, embedded, so-far folded, this thread’s domain-next + timestamp rewritten.
  7. Continue. Once there is a typed dump and the sitting is not synced, the starter is used up. A continuation callout follows — a notice, not a hello, not a recap. Do taps do not trigger this. Sync kills it.
Browsing lunch options? Before you pick, quietly wait and watch cravings arise and pass, just like the late night urges.

A nice idea, or a question-kinda statement — never homework. Not “Browse Zomato for lunch, quietly watching…, in Sakshi Bhava.” Not a doorbell. Not a sitting essay.

A thread may retrieve

  • The dump, verbatim, and any prior dump still on this sitting
  • This thread’s so-far, next, clock, live ideas, and blurb
  • What this thread already filed earlier in this sitting
  • Recent group turns (faces, not a second copy of the dump)
  • The domain’s title

A thread must not

  • About / rhythm; other threads’ private so-far
  • Invented facts or invented clocks
  • Homework, skip / mute / missed-window talk
  • Echoing the dump as the face; pasting moves, clocks, notation
  • Clerk voice; asking them to fill the structure as a form

If the model fails, or the face is a synonym of the dump: salvage from this thread’s next or so-far, or stay silent.

03 · Sync — leaving the room

Two ways in:

  • They merge / Sync. Always leave this sitting.
  • Quiet. No user turn for about two hours, and there is substance. A gate may ask “is this still mid-arc?” If yes, leave the overlay as-is. If the gate fails, leave the room anyway — fail open.

Hide is not Sync. Hide is not merge.

Sync does not re-read beats into a recap, rewrite so-far or next, or mint threads. Memory already landed on the dump.

Sync does: stamp the sitting closed, wipe the chorus transcript, drop the per-app callout cache for this domain so the next open cannot ignore the nexts that just changed, and may search a live object from those nexts.

North Star folds on the dump if classify touched it (they named want / avoid / when). Sync does not re-fold identity.

04 · Chips

The door is a line. A chip is only allowed if it is a Do: a real object in the room they can open right now. At most two. Live card first, then pantry. If neither serves a current next, show nothing.

Sit as a tap is retired. Two likely typed moves are generated with the line and shown as cycling placeholder text in the composer — not as taps. “Suggest a meal.” “Log my order.” If they want to answer, they type.

Do selection, in order

  • Live card — after a merge, if some thread’s next is a named object in the world, Savyn may search once and park one live link for this domain. Chip only. Never silently saved to pantry.
  • Pantry — links they actually saved to this domain. A picker matches pantry rows against current nexts and keeps at most two that serve a next. A random saved article is not a chip.

No third step. Associated app is not a chip. They already opened the app from the widget. “Open Hevy” is not a sitting move. The language model is forbidden from inventing URLs. When the line names a specific object, that noun matches live card and pantry. If nothing in the room is that object: silence. An idea-only line is not a Do.

Every Do makes two things obvious: the move (“Caro lesson,” “Play 10+0”) and where it opens (YouTube, Chess.com, Hevy). Tap launches. Not a turn, not a beat, not a chorus, not a continuation.

Chips are not three synonyms of the liner, recovery homework, a “smaller whisper,” or a second composer. If a chip cannot open a real object, it should not exist.

05 · What the door may know

The starter is an app-hour orientation, not a sitting recap. The packet is small on purpose.

Always. Current time. Domain title. If they opened an app: that app’s display name.

Domain-next roster — soonest clock first, a handful of lines. Each line is one work thread’s next + expected timestamp (or none). Not every thread. Not today’s recaps. Not sitting beats.

Never. The North Star as a goal to solve, or the whole spine on every open. So-far novels. Lifetime episodes. Invented clocks. Invented nouns that are not on a next line. A line that goes against a live clause. A late-night avoid quoted at noon.

The door does see a clipped North Star. Most hours it stays quiet. It may use one clause only when this app + this clock make that clause live (Swiggy at 1am × avoid late-night snacking).

Continuation (after a typed dump, sitting still open) is a different job: last move + chorus + soonest nexts. It does not overwrite the per-app starter cache. A Do tap does not write a continuation. Dump-kind is not a door packet. The app’s name is the grain (Swiggy = order, Hevy = train).

06 · Objects in the room

Search exists for one reason: next named a thing in the world, and a practitioner would Google that thing.

  • If the live card still matches the current next, keep it.
  • If next is a vague practice (“keep training,” “check in”), stay silent. No search.
  • If next is a named object, pick at most one query — what someone in this life would actually type — resolve it, park a card. Then read what the page is (kind, nouns, a two-to-five-word verb) from the page itself plus a small model. The Open Graph title is not the chip.

Failures clear the card. Changing next clears it. The person can later save that URL into the pantry on purpose. The system never writes the pantry for them. The pantry survives merge. Associated apps are mapped to the domain; opening one from the widget is the sitting. That launch is not a chip.

07 · Failures, on purpose

Intelligence here is mostly knowing when to shut up. The product prefers a thin true memory to a thick invented one.

FailureWhat Savyn does
Callout has no lived nounReject the line; fall back to a next, not a welcome
No Do that serves a nextSilence. Do not invent a link or fill with Sit taps
App unknownDomain-level line. Do not fake Swiggy-voice
Classify finds no threadSay nothing rather than recap the roster
A thread would only echo the dumpSilent, or salvage from that thread’s next / so-far
Sync has nothing new to rememberStill leave the room; memory already filed on the dump
Search has nothing namedNo live card
Overlay hiddenSitting remains. No fold

08 · One sitting, end to end

They open Swiggy at 6pm from Food.

  • The starter door is the Swiggy line: time, app name, soonest Food domain-nexts. No Sit chips. Says cycle in the composer. A Do only if a real object is in the room.
  • They type a dump. Classify names Nutrition. Nutrition writes the episode beat from its blurb (calories, profile, meal times), folds so-far, rewrites its domain-next + lunch clock. Game analysis stays quiet. Then a continuation on the sitting — not a rewrite of the Swiggy cache.
  • A Do tap only opens the URL. No chorus.
  • They leave. Overlay hides. The sitting is still open. Memory already landed.
  • When they Sync (or quiet close), chat clears. The Food callout cache is dropped. Next Swiggy open writes a fresh line from the new domain-next roster.

That is the intelligence: the door names the move on this app this hour from the closest next, the threads read and remember on the dump, Sync only leaves the room, and chips are only real objects this life can open.

09 · How each entity is written

Every writer below is a separate job. They do not share one prompt. What one is allowed to see, another is forbidden from seeing — that is the point.

For each: when it runs, the job it is given, the packet it is fed, what it must return, what happens to the result, what happens if it fails. In raw job text, “house” means thread. “Track” means domain.

9.1 North Star

When
Created once per domain (onboarding, or seeded from legacy about + rhythm). Folded on a dump if classify touched it — they named how they want to live, what to avoid, or when. Overlay open ensures it exists.
What
A special fixed thread. One editable prose spine (want / avoid / when). No next. No episodes. No beat-structure form. Not a Do. Classify touches it only for identity / avoid / cadence dumps.
Packet
Current guidelines. Fold only if they named identity, avoid, or when.
Return
Optional fold into the same paragraph. Short. Guidelines, not a recap of the plate.
Then
Absorbed into the thread’s so-far. About / rhythm are not written.
Fail
Prior North Star stands. The door still only uses a clause when the moment needs it.

9.2 Rhythm — retired

Note
Cadence lives on the North Star as “when.” Legacy about + rhythm seed the North Star once, then those dimensions are cleared.

9.3 So-far

When
Same beat call as the episode, on each dump this thread filed. They do not type so-far as a field in chat.
Job
Update thread memory from this dump. Do not retell the episode. Fold prior so-far + this episode beat into continuity. Advance what changed; drop noise. Do not copy this episode. Good: prior “Building an openings book” + episode drilled Caro structure → “Openings book is live; Caro structure is the edge.”
Packet
This thread only: name, blurb, prior so-far, next, the dump, this sitting’s prior beats on this house.
Return
so_far — short continuity, not a second recap.
Then
Replaces the thread’s so-far. Survives overlay hide. The next door and the next beat both read it.
Fail
Prior so-far is kept; the episode may still be filed.

9.4 Domain next

When
Same beat as the episode — always rewrite this thread’s line, unless the path closed. Also: they edit the line in the book; creating a thread can seed it; changing next clears any live link keyed to the old next.
Job
One line for THIS thread on the domain roster. Their nouns. Not a chore, not seating copy, not skip-guilt. Also next_at: an honest local clock only if this dump implies one. Empty if unstructured — never invent 7:00 for Game analysis. Good: “protein’s thin — lunch is the hole” + 13:00.
Return
next + next_at (ISO or HH:mm or empty).
Then
Stored on the thread. Roster is these lines, sorted by soonest clock (none at the back). Guilt language stripped. The door speaks from the closest. Search may run from a named object on a next.
Fail
Old next and clock remain.

9.5 Episode (the beat)

When
After classify names this thread. Parallel, one writer per touched thread. Not on Do tap. Not delayed until Sync.
Job
You are ONE continuity thread. Follow YOUR JOB — the beat-structure blurb. Infer. Never a clarifying question. Never paste moves, PGN, clocks. Never homework. Never skip/mute/missed. Never invent. Never a synonym of their dump as the face. The episode is this beat.
Packet
“You are the thread {name}.” + YOUR JOB. Domain title. So-far, next, clock, live ideas for this thread only. This sitting already on this thread. Their dump, verbatim. Prior dump still on this sitting if follow-up. Recent group — faces, context only. Not in the packet: about, rhythm, other threads’ so-far, last episode as an ask, URLs.
Then
Face shown in the chorus. Episode stored, embedded, so-far folded, domain-next + clock rewritten. Thread marked touched. Callout cache for the domain dropped.
Fail
Soft fallback face from a dump liner. If the face is an echo, salvage from next or so-far, or silence. Empty is better than a polite recap. Threads are not auto-created from a dump.
face      ≤12 words, no brackets — the plate line
episode   the beat following YOUR JOB (this is the episode)
so_far    thin spine
next      ≤12 words, this thread’s domain-next line
next_at   ISO-8601 local, HH:mm, or empty

9.6 Beat-structure blurb

When
Onboarding authors it from their words. Manual add — LLM authors from what the path is for. Existing living threads — one-time backfill if missing. They may edit it any time in the thread book.
What
Prose charge for the beat writer. Not JSON, not a table, not INPUT/INFERRED legs. Brand-new thread: blurb only. No next. No so-far. Those appear after real dumps.
Defaults
Fallback only if the model is down. Nutrition → calories, nutritional profile, meal times. Fitness → body parts + recovery. Game analysis → unstructured. North Star has none.

9.7 Classify

When
Every user dump. Skipped if they replied to one member — that thread only. Never on Do tap.
Job
Name which continuity threads a dump actually moved. Include a thread if the dump has substance for it — even first touch. Exclude a thread that would only politely recap. Empty touched is allowed. North Star only if they named want / avoid / when.
Packet
Domain title. Dump (verbatim). Prior dump still on this sitting if any. Threads with exact ids, names, next, so-far. Recent group (context only).
Return
{ "touched": [thread ids…] } — ids must be from the packet. Cap a handful. Then those threads write episode beats in parallel.
Fail
Heuristic: analysis-shaped dumps route to an analysis thread if one exists; else any thread whose name appears in the dump. If still empty: a quiet “nothing here had a thread.”

9.8 Starter callout

When
Lazily on open, for this (domain, app) key — or (domain, none). Rewrite if stale (~1 hour) or day-part flipped. A dump that rewrote domain-next, and Sync, drop every key on that domain. A background slot pass does not rewrite all domains.
Job
One lived line: what they would be doing RIGHT NOW on THIS app. Idea or question-statement — never homework. App + clock are the situation. Soonest domain-next lines are the nouns. Do not invent a lunch, a session, fiber, or a 7:00 that is not in the packet. ≤24 words. Two typed says. Optional do_object. North Star: ignore unless one clause is live.
Then
Formula / guilt / homework / trash liners rejected. Dos from live card / pantry only. Fail: the soonest next as the line. No Sit fill.
liner       ≤24 words, idea or question-statement, this app this hour
says        two short typed moves (composer placeholders)
do_object   named object if the line suggested one; else empty

9.9 Continuation callout

When
Sitting has at least one typed dump. Last dump is newer than last Sync. Fingerprint = last turn’s time. Does not rewrite until something new lands. Not after a Do tap.
Job
This sitting already started. Write the next line — a notice, not a hello, not a doorbell, not homework. You were in the room for THEIR LAST MOVE. Name the next beat in their nouns. If they dumped, do not recap. Two typed says. Optional do_object.
Packet
Domain title. Clipped North Star (ignore unless one clause is live). Episode: open, not synced. Their last move. Threads just said — chorus faces. Domain-next roster, soonest first, plus so-far for those threads.
Return
Liner ≤22 words. Two says. Optional do_object. No Sit chips. Stored on this sitting until Sync or a newer dump. Fail: soonest next as the line. If even that is empty, no continuation plate.

9.10 Sit chips — retired

Note
The two says from the door writer are cycling placeholder text in the composer, not taps. They are the most likely typed moves. They are not a second chip row.

9.11 Do chips

When
After a liner exists. Two sources, in order. None invent a URL from the door prompt. Live card first (verb = about-verb). Then pantry pick — at most two links that serve a current next. Skip any Do whose verb is “Open this” or “Open {app}.” When the liner named a specific object, mix prefers rows that match that noun. Still no invented URL. Mix: max two Dos. Tap: launch. Never a turn. If none serve a next: silence. The line stands alone. Says still cycle.

9.12 Live object

When
After a dump (or Sync) has written domain-nexts. If a live card still matches the current next, keep it. Never auto-save to pantry.
Job
Pick at most ONE next that is genuinely served by a specific article, talk, paper, recipe, study, course, book, puzzle set, or video. “Keep practicing” is a no. A named dish they ate is a yes. Silence is correct when you cannot name a real object. object = ≤6 words, the Do chip verb. query = what a practitioner types into Google. Proper nouns. Never “tips for X”, “how to Y”, “best practices”, “healthy/easy/quick.”
Return
{ hub_id, object, query } or empty. Query is resolved on the web. First real URL parked, keyed to that thread + exact next. Then link-about writes the verb. Fail: card cleared. Trash queries rejected before search.

9.13 Link about

When
We already have a URL — live card enrich, or they saved a link. Never search. Open Graph title/description fetched if missing.
Job
Say what it is for a sitting door chip. kind = recipe | video | game | article | order | course | other. nouns = 1–2 lived nouns. verb = 2–5 word chip they’d tap to GO there. Never the OG headline. Never a Sit dump. line = one short clause of what it is.
Fail
Host heuristic (YouTube → video / Watch this; chess.com → game / Play this; recipe hosts → Cook this; else Open this from the title).

9.14 Pantry pick

When
Attaching Do chips. Pantry is links they saved to this domain. Survives merge. Max a dozen.
Job
Pick the links that actually serve a next — a named object they’d open for THAT next. Not same-domain-so-close-enough. At most 2. Empty ids if none belong.
Return
{ "ids": [exact pantry ids] }. Fail: no pantry Dos. The line stands alone.

9.15 Quiet Sync gate

When
Unsynced user dumps and ~2h since the last one. Manual Sync skips this and always leaves the room.
Job
Decide whether this sitting should close after a quiet gap. True when the bout feels naturally paused. False when they are clearly still mid-arc. Memory is already filed — this gate is only about leaving the room.
Return
{ "needs_merge": true | false }. True → leave the room. False → leave the overlay as-is. Fail: default true — fail open so a sitting is not stranded open.

11 · Output shapes

Face on the plate is the short line. The episode is stored, embedded, and shown in the thread book.

# Beat — this is the episode
face      ≤12 words — the plate
episode   the beat following the structure blurb
so_far    thin spine
next      this thread’s domain-next line
next_at   ISO / HH:mm / empty — never an invented 7:00

# Door
liner:      ≤24 words, idea or question-statement, this app this hour
says:       two typed moves — cycling composer placeholders, not taps
do_object:  named object if the line suggested one; else empty
chips:      Do only, from live card / pantry — never Open {app}. Silence if none
key:        (domain, app) or (domain, none)
packet:     soonest domain-next lines, not every next + today’s recaps

# Sync
No model recap. Leave the room. Drop the door cache.

# Live link pick
hub_id, object (chip verb), query (what to search)   — or all empty

# Link about
kind, nouns, verb, line

# Pantry pick
ids: [saved link ids]   — at most two, or none

Each entity has one job, one packet, one shape.

And a silence that is cheaper than a lie.
