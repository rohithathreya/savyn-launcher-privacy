00

Savyn is not a chat app.

It is an OS layer on your phone. Your life is split into areas — Food, Fitness, Chess, People. Each area has a home on the widget. When you open Swiggy, you are not “in a chatbot.” You are in Food, on Swiggy, at 6pm.

Savyn’s job in that moment is small and strict:

  • Say one lived line about what you’d actually be doing on this app, right now.
  • Let you type whatever is true.
  • Remember what that meant for the paths in this life that actually moved.
  • Offer a tap only if there is a real object in the world to open — a lesson, a recipe, a board. Otherwise offer nothing.

That loop is a sitting. Everything below is how a sitting is not allowed to become a clerk.

01

A sitting is time in a life.

You tap Food. You open Swiggy. An overlay is already that life. You can hide it and the sitting is still open. You have not “closed the chat.” You have just looked away.

Two different acts get confused in every other product. We split them on purpose:

  • Speaking — you type (or dictate). That is a turn. Memory is written from that text.
  • Doing — you tap something that launches YouTube, Chess.com, a recipe. That is not a turn. No memory. No “they left to go do…”

Leaving the room is a third act. We call it Sync. It clears the open conversation. It does not write memory. Memory already happened when you spoke.

02

Your life is rooms.

Food is not Fitness. Opening Hevy does not borrow Swiggy’s voice. Each room — we call it a domain — is a life you keep showing up to.

A domain has one paragraph for how you want to live there: what you want, what you avoid, when. We call that the North Star. It is not a goal list and not a lecture. Most hours Savyn ignores it. It may use a single clause only when this app and this hour make that clause actually live — Swiggy at 1am, and you asked to avoid late-night snacking.

A domain also keeps a roster of “what’s next” for each path inside it. One line per path. If a path has an honest time (lunch is the hole, 13:00), that time sits on the line. If a path has no time — game analysis, wandering — the clock stays empty. Savyn never invents 7:00 because a model likes mornings. The door reads this roster from the soonest clock. Unclocked paths wait at the back.

03

Inside a room, paths.

Food is not one thought. Nutrition is a path. Eating out is a path. They are not hashtags. They are how Savyn reads what you just said.

We call a path a thread. The first set is seeded when you arrive. You can add and edit. Savyn does not invent a new path every time you type.

Each thread carries four things, and only four:

Blurb
A short prose charge, written at create, editable later. Nutrition might say: calories, profile, meal times. Game analysis might say: this path is unstructured — stay unstructured. This is the job the model is given. Not a form. Not JSON.
So-far
A thin spine of this path across days. Folded forward every time this thread files. Short on purpose. Not a novel. Not a recap of the last sitting.
Episodes
Each time this thread files, that filing is an episode. Stored and searchable. Not a summary written later when you leave.
Next
This thread’s one line on the domain roster, plus a clock if the dump implied one. New threads have none until a real dump writes one. You can edit the line. Never “you skipped.”

North Star is a special thread: paragraph only. No next. No episodes. No blurb-as-form. Ideas on a path (a book, a method) are facilitators, not new rooms.

04

You type. Memory lands.

You write: late dinner, mostly rice, ~900. That text is a dump. A first model looks at every thread in this room and names the ones this dump actually moved. We call that classify. Empty is allowed. If nothing moved, Savyn says nothing — it does not recap the roster to fill the silence.

If you replied to one thread only, only that thread answers.

Each named thread then writes, in parallel, following its own blurb. Nutrition infers calories and meal time. Game analysis, if it wasn’t touched, stays quiet. There is no clarifying question. Infer, or stay silent.

What that thread writes is called a beat. The beat is the episode. Same call: store it, embed it, fold so-far, rewrite this thread’s next line and clock. You have not pressed Sync. You have not saved. It already happened.

Tapping a chip does none of this.

05

Before you speak: one line.

You opened Swiggy. You have not typed yet. Savyn owes you a line. Not a paragraph. Not homework. A nice idea, or a question that is almost a statement, about what you’d be doing on Swiggy, at this hour.

Browsing lunch options? Before you pick, quietly wait and watch cravings arise and pass.

That line is the door. It is keyed by room and app: Swiggy ≠ Zomato ≠ Hevy. A day is 6am to 6am, local. The line is rewritten lazily — about an hour, or when morning turns to afternoon. Hiding the overlay does not rewrite it. A dump that changed “what’s next” does, so the next open can see it.

The door is allowed to know: the time, the room’s name, the app’s name, a handful of the soonest next-lines, and a clipped North Star it should usually ignore. It is not allowed to know your so-far novels, your lifetime episodes, today’s recaps, or a 7:00 nobody wrote down.

Once you have typed and you have not Synced, the first hello is used up. The next line is a continuation: a notice about what you just did, not a recap, not another doorbell. Tapping Do does not earn a continuation. Sync kills it. The next time you open Swiggy, you get a new starter from the roster the beats already wrote.

06

A tap must open something real.

The door is a line. Under it, at most two chips. A chip is only legal if it is a Do: it launches a URL or an app that already exists in this life. “Open Swiggy” is not a chip — you already opened Swiggy. “Keep going” is not a chip. Three paraphrases of the line are not chips.

If you want to answer the line, you type. Two likely typed moves cycle as placeholder text in the composer (“Suggest a meal”, “Log my order”). They are not buttons. Sit-as-a-tap is retired.

Where a Do comes from, in order:

  • Live card — after memory rewrites “what’s next,” if that next is a named object in the world (a book, a course, a recipe, a video), Savyn may search once and park one link for chips. It does not save that link for you.
  • Pantry — links you actually saved to this room. A picker keeps at most two that serve a current next. A random saved article is not a chip.

The model is forbidden from inventing URLs. If the line named a specific object and nothing in the room is that object: silence. Search itself is forbidden unless next named a thing a practitioner would Google. “Keep training” is not a search. Failures clear the card.

Every legal Do shows two things: the move (“Caro lesson”, “Play 10+0”) and where it opens (YouTube, Chess.com). Tap launches. That is the whole event.

07

Leaving is not remembering.

You Sync, or you go quiet for about two hours with substance on the sitting. A small gate may ask if you’re still mid-thought. If the gate fails, Savyn leaves anyway — a sitting must not be stranded open.

Sync stamps the sitting closed, wipes the open conversation, and drops the door cache for this room so the next open cannot ignore the nexts that just changed. It may then look for one live object from those nexts.

It does not re-read beats into a recap. It does not rewrite so-far. It does not mint new threads. Hide is still not Sync.

08

Four jobs, kept apart.

If one voice does all of this, you get a clerk. So the machine is four jobs that are not allowed to share a prompt.

Callout
The door

What you’d be doing on this app this hour. Speaks from the soonest next, not the whole board.

Threads
The reading

What this dump meant for this path, following that path’s blurb.

The beat
Memory

On the dump: file the episode, fold so-far, rewrite next. Sync writes nothing.

Links
The object

A real next they can open. Attached after the line. Never invented.

09

Each writer is a contract.

When it runs. What it is allowed to see. What it must return. What happens if it fails. Threads are never created from a dump.

North Star how you want to live here

WhenOnce per room. Folded on a dump only if you named want, avoid, or when. InThe current paragraph. OutAn optional short fold into that same paragraph. Not a recap of what you just typed. FailThe old paragraph stands.

So-far the spine of a path

WhenSame call as the episode, every dump this thread filed. InThis thread only: blurb, prior so-far, next, the dump, earlier beats this sitting. OutA short spine. Advance what changed. Do not retell the episode. FailKeep the old spine. The episode may still file.

Next one line on the room roster

WhenEvery beat, unless the path closed. Also when you edit it. Changing it clears any live link tied to the old next. OutOne line in their nouns, plus a clock only if this dump implied one. Empty if unstructured. FailOld line and clock remain. Guilt language is stripped on write.

Episode the beat

WhenAfter classify names this thread. Parallel. Not on a Do. Not delayed until Sync. In“You are thread {name}.” Your blurb. This room’s title. This thread’s so-far / next / clock / ideas / earlier beats. The dump, verbatim. Faces from others, as context. Never other threads’ private so-far. Never URLs. OutA short face for the plate (≤12 words), the episode in the shape the blurb asked, a new so-far, a new next, a clock or empty. FailSalvage from this thread’s next or so-far, or silence. Empty beats a polite recap.

Classify which paths speak

WhenEvery typed dump. Skip if they replied to one member. Never on Do. InRoom title, dump, prior dump, each thread’s id / name / next / so-far, recent faces. OutA list of thread ids from that packet. Empty allowed. North Star only for identity / avoid / when. FailA small heuristic, then quiet.

Starter door before they have spoken

WhenOn open, for this room + app. Rewrite if stale (~1h) or the day-part flipped. A dump that changed next, and Sync, drop every key on this room. InTime, room, app name, clipped North Star, soonest nexts. OutLiner ≤24 words, two typed says, optional named object. Homework and guilt rejected. Dos attached from live card / pantry only. FailThe soonest next as the line. No fake chips.

Continuation after a turn, not synced

WhenAt least one typed dump, newer than last Sync. Not after a Do. InLast dump, faces just said, soonest nexts + so-far. OutLiner ≤22 words, two says, optional object. Dies on Sync. FailSoonest next, or no plate.

Live / about / pantry objects in the room

LiveAfter next rewrite. At most one next that is a named object. Query = what a practitioner types. Never “tips for” / “how to” / “best.” Never auto-save to pantry. AboutWe already have the URL. Kind, nouns, a 2–5 word verb they’d tap. Never the Open Graph headline. PantryLinks they saved. Pick ≤2 that serve a current next. Not “also this life.”

Quiet gate whether to leave after ~2h

OutLeave, or keep the overlay. Memory is already filed. If the gate fails: leave. Fail open.

11

What “written” means.

beat
  face      ≤12 words     the line on the plate
  episode   blurb-shaped  stored, embedded, in the book
  so_far    thin spine
  next      ≤12 words     this path on the room roster
  next_at   a real clock, or empty

door
  liner      ≤24 words    this app, this hour
  says       two phrases  cycling in the composer — not taps
  chips      Do ≤2, or none

sync     no model. leave. drop the door cache.
12

One hour in Food.

  1. 6pm. Swiggy. Food. The door is one Swiggy line from the soonest Food nexts. No Sit chips. Two likely typed moves cycle in the field. A Do only if a real object is already in the room.
  2. They type. Classify names Nutrition. Nutrition writes the beat its blurb asked for, folds so-far, puts a lunch clock on its next. Game analysis stays quiet. A continuation follows on the sitting — the Swiggy cache is not rewritten.
  3. A Do tap opens a URL. Nothing else happens.
  4. They hide the overlay. The sitting is still open. Memory already landed.
  5. They Sync. Conversation clears. Food’s door cache drops. Next Swiggy open writes a new line from the roster the beat already changed.

The door names the move. The paths remember when you speak. Sync only leaves.

A chip opens a real object, or it does not exist.
